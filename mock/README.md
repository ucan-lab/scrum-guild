# 画面のモック

見た目と画面の流れを合わせるためのモック。HTML、CSS、JS だけで、ビルドは要らない。`index.html` をブラウザで開けば動く。

- データはすべて架空の例で、操作は保存しない。
- 言葉はスクラムの言葉で出す。右上のボタンで、配色（OS に合わせる、ライト、ダーク）を切り替えられる。
- 作った画面は、自分の今日、バックログ、スプリントの列、計画と積載量、エピック、タスクの詳細（一覧の行かカードを押すと開く）。受信箱、アーカイブ、接続、設定は2周目で作る。
- 色と文字の大きさは `styles.css` の先頭の CSS 変数にまとめてある。本番の画面でもこの変数を引き継ぐ。
