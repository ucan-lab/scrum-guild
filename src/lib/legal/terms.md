この規約は、Scrum Guild（以下「本サービス」）を使う人と、本サービスを運営する人（以下「運営者」）の間の約束を定めます。本サービスを使う前に読んでください。データの扱いは、別の「プライバシーポリシー」に書いています。

# 第1条 本サービスについて

本サービスは、チームのタスクを集め、ゲームの仕組みで回すための Web サービスです。組織、ワークスペース、エピック、ストーリー、タスクなどを作り、チームの仕事を進めるために使います。

本サービスを使った人は、この規約に同意したものとみなします。

# 第2条 アカウントとログイン

- ログインできる手段は、GitHub と Google のアカウントです。本サービスはパスワードを預かりません。
- 組織は運営者が作るほか、会員が自分で作れます。会員が自分で作った組織では、その会員が最初の管理者になります。組織を使えるのは、その組織に所属している人と、招待された人です。
- ログインに使うアカウントと API トークンは、本人が責任を持って守ってください。他の人に使わせないでください。
- 自分のアカウントや API トークンが他の人に使われたと気づいたときは、すぐに組織の管理者か運営者に伝えてください。

# 第3条 組織と管理者

- 組織には管理者がいます。管理者は、組織のメンバーの招待と無効化、ワークスペースや設定の管理をします。
- 組織の中の操作は、それぞれの人に許された権限の範囲に限られます。別の組織のデータは見えません。
- 組織に入れる人数と添付ファイルの合計の容量には上限があります。上限は組織の段階ごとに決まり、運営者が変えます。

# 第4条 組織の一時停止

- 運営者は、支払いの遅れなどのときに、組織を一時停止することがあります。
- 一時停止した組織には、だれも入れません。取り込みなどの定期の処理も止まります。データはそのまま残ります。
- 運営者が再開すると、組織をまた使えます。

## お試し

- 会員が自分で作った組織は、30日間のお試しで使えます。1つのアカウントが作れるお試し中の組織は1つまでです。
- お試しの期限が過ぎた組織は、自動で一時停止します。期限の日の終わり（UTC）までは使えます。
- 運営者が一時停止した組織を再開した時点で、お試しは終わります。以後、その組織は期限では止まりません。

# 第5条 預けたデータ

- 組織に入力したタスク、コメント、添付ファイルなどのデータの権利は、利用者と組織に残ります。
- 運営者は、本サービスを提供し、保守し、不具合を調べるために必要な範囲でだけ、そのデータを扱います。
- データの種類、預かる期間、消す時期は、プライバシーポリシーに書いています。
- 取り込み元（Backlog、GitHub など）の本文は、既定では預かりません。管理者が組織の設定で選んだときだけ預かります。

# 第6条 してはいけないこと

次のことは、してはいけません。

- 法令や公序良俗に反すること。
- 他の人のアカウントや API トークンを使うこと。
- 権利を持たないデータや、他の人の権利を侵すファイルを上げること。
- ウイルスなど、本サービスや他の人の機器を害するものを上げること。
- 本サービスの運営を妨げること。操作の回数の上限を避ける工夫も含みます。
- 運営者の許しなく、本サービスの安全性を試すこと。

これに当たると運営者が判断したときは、運営者はその利用を止め、組織を停止することがあります。

# 第7条 バックアップ

- 本サービスには、利用者向けのバックアップと復元の機能はありません。
- 添付ファイルは、バックアップを取りません。消したファイルは戻せません。
- データベースは、運営者が障害に備えて過去 30 日の状態に戻せるようにしています。消したデータは、その間、この控えに残ることがあります。ただし、利用者の求めに応じて、控えからデータを戻すことは約束しません。

# 第8条 解約とデータの消去

- 解約した組織は、解約にした日（一時停止の後に解約へ切り替えたときは、切り替えた日）から 30 日後に、運営者がデータをすべて消します。添付ファイルも消します。
- 消す予定日の当日までは、再開できます。予定日を過ぎると、再開できません。消したデータは、運営者が戻すことはありません（第7条の控えからの復旧も約束しません）。
- 組織から抜けるときは、管理者がそのユーザーを無効にします。無効にしても、その人の名前、完了の記録、経験値は、組織の履歴として残ります。
- 一時停止している間は、解約に切り替えるまでデータを消しません。

# 第9条 本サービスの変更、中断、終了

- 運営者は、本サービスの内容を、予告なく変えることがあります。
- 保守や障害のために、本サービスを止めることがあります。
- 本サービスを終えるときは、事前に本サービスの中で知らせるよう努めます。

# 第10条 保証と責任

- 本サービスは、現状のまま提供します。運営者は、本サービスに不具合が無いこと、特定の目的に合うこと、データが消えないことを保証しません。
- 運営者は、運営者の故意または重大な過失による場合を除き、本サービスを使えなかったこと、データが失われたことによる損害の責任を負いません。
- 利用者の間や、利用者と第三者の間の争いは、利用者が自分たちで解決してください。

# 第11条 規約の変更

運営者は、この規約を変えることがあります。変えたときは、このページを改定日つきで改めます。重要な変更は、事前に本サービスの中で知らせるよう努めます。変更の後に本サービスを使った人は、変更後の規約に同意したものとみなします。

# 第12条 準拠する法律と裁判所

この規約は、日本の法律に従います。本サービスについて争いになったときは、（管轄する裁判所を入れる）を第一審の専属の合意管轄の裁判所とします。
