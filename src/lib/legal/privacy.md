このポリシーは、Scrum Guild（以下「本サービス」）が預かる情報と、その扱いを定めます。本サービスを運営する人（以下「運営者」）が、このポリシーに従って情報を扱います。

# 第1条 預かるもの

本サービスが預かるのは、次の情報です。

- ログインの情報。GitHub か Google のアカウントの識別の番号、表示の名前（GitHub のログイン名、Google のプロフィールの名前）、アイコンの画像の URL、最後にログインした日時。
- 組織でのメンバーの情報。組織での表示名、ロール、稼働の設定、休暇の予定。
- 招待の情報。Google のアカウントで招待するときは、招待の宛先のメールアドレス。招待した人と管理者の画面に出ます。
- 組織のデータ。組織とワークスペースの名前と設定、エピック、ストーリー、タスク、コメント、完了の記録、経験値、感謝、通知、スプリントなど、利用者が入力したもの。
- 添付ファイル。タスクやコメントに上げたファイルの中身と、ファイル名。
- 操作の記録。組織の中の変更の履歴（だれが、いつ、何を変えたか）。
- 取り込み元の情報。取り込み元（Backlog、GitHub など）につなぐ組織の認証情報は、暗号化して預かります。取り込むのは、タイトルなど、タスクとして扱うのに要る属性です。
- ログインを保つための情報。セッションの Cookie に入れた乱数と、その乱数から作った照合用の値。API トークンから作った照合用の値。
- 回数の上限を守るための情報。ログインなどの操作の回数を数えるために、通信元の IP アドレスを短い間だけ預かります。
- 画面の不具合の報告。画面で起きたエラーの名前、メッセージ、画面の経路（組織の名前や ID を除く）。

# 第2条 預からないもの

- 取り込み元の本文は、既定では預かりません。タスクの本文を含む取り込み元の応答は、管理者が組織の設定で選んだ組織だけが預けられます。選ばなければ、タイトルなどの属性だけを預かります。
- GitHub と Google のパスワードは預かりません。本サービスは、ログインの手段の側で本人を確かめた結果だけを受け取ります。
- クレジットカードの番号など、支払いの情報は預かりません。支払いは、本サービスの外で扱います。
- 広告のための情報と、利用状況を解析するための Cookie や外部の計測サービスは使いません。本サービスが使う Cookie は、ログインを保つものだけです。

# 第3条 使い道

預かった情報は、次のことのために使います。

- 本サービスを提供すること（ログイン、組織の中の表示と操作、通知）。
- 本人を確かめ、権限を守ること。
- 不正な使い方や過度な負荷から、本サービスを守ること。
- 不具合を調べて直すこと。
- 規約やこのポリシーの変更など、本サービスについて知らせること。

預かった情報を、広告に使いません。法令に基づく場合を除いて、本人の同意なく第三者に渡しません。

現在、本サービスは、利用者のデータを AI のサービスに送っていません。送る機能を足すときは、先にこのポリシーを改め、管理者が有効にするまで使えないようにします。

# 第4条 預け先と外部のサービス

- 情報は、Cloudflare のサービス（Workers、D1、R2）に保管し、処理します。サーバーは国外にある場合があります。
- ログインのときに、GitHub または Google に本人の確認を頼みます。このとき、それぞれのサービスの規約とポリシーも適用されます。
- 取り込み元と連携する組織は、そのサービスと通信します。

# 第5条 ログに出さないもの

運営者が見る運用のログに、本文、取り込んだ内容、認証情報（パスワード、トークン、Cookie の値、招待の URL の秘密）を出しません。ログに残るのは、操作の名前、結果、所要時間、時刻などです。

# 第6条 消す時期

- 解約した組織のデータは、解約にした日（一時停止の後に解約へ切り替えたときは、切り替えた日）から 30 日後に、運営者がすべて消します。添付ファイルも消します。消す予定日の当日までは、再開できます。
- 一時停止している組織のデータは、解約に切り替えるまで消しません。
- 組織から抜けた人（管理者が無効にした人）の名前、完了の記録、経験値は、組織の履歴として残します。取り込み元につなぐ認証情報は、抜けるときに消します。
- ログインのセッションは、最後に使った日から 30 日で切れ、切れた分は定期の処理で消します。ログアウトすると、そのときのセッションをすぐに消します。
- API トークンは、発行から最長 90 日で切れ、切れた分は定期の処理で消します。取り消したトークンは、すぐ使えなくなります。
- 回数を数えるための IP アドレスは、数える窓が過ぎたら、定期の処理で消します。
- 添付ファイルは、バックアップを取りません。消したファイルは戻せません。
- データベースは、障害に備えて、過去 30 日の状態に戻せるようにしています。消したデータは、その間、復旧のための控えに残ることがあります。

# 第7条 安全のための取り組み

- 通信は HTTPS で行います。
- セッションと API トークンは、乱数の値そのものでなく、照合用の値だけを保存します。
- 取り込み元の認証情報は、暗号化して保存します。
- 組織のデータは組織ごとに分け、別の組織の人には見せません。
- 添付ファイルは、権限を確かめた人にだけ返します。

# 第8条 開示、訂正、削除の求め

自分の情報の開示、訂正、削除を求めるときは、下の問い合わせ先に連絡してください。本人かどうかを確かめたうえで、対応を相談します。

- 組織の履歴として残しているもの（組織から抜けた人の名前、完了の記録、経験値、変更の履歴）は、消しません。ほかの人の記録や、組織の仕事の記録とつながっているためです。
- アカウントを削除する手順は、今はありません。求めがあったときは、個別に相談します。

# 第9条 このポリシーの変更

このポリシーを変えたときは、このページを改定日つきで改めます。重要な変更は、事前に本サービスの中で知らせるよう努めます。
