# seed

手元の D1 と e2e に入れる架空のデータ。名前は `design/sample-data.js` から取った。

```bash
pnpm db:seed
```

流すのは `scripts/db-seed.ts` で、手元の D1 に全マイグレーションを当て、マイグレーションの記録を除く全部の表の行を消してから入れ直す。手で足した行も消えるので、何度流しても同じ状態に戻せる。

| ファイル | 中身 |
| --- | --- |
| `data.sql` | 固定の行。組織3つ（あおば開発、ひばり工房と、末尾の e2e 専用のくもラボ）、ユーザー（あおば開発には、e2e の組織の管理のユーザーの節（`e2e/users.test.ts`）だけが指名、解除、無効化、有効化する、所属もアカウントも無いソラとユイを含む。ソラは受託開発チームへの承諾待ちの招待と同じログインを持つので、管理者にしても組織の人数は変わらない）、組織の休日（あおば開発に3日、ひばり工房に1日）、ワークスペース（受託開発チームはゲームの言葉、社内ツールはスクラムの言葉、ひばり工房のデザイン相談室はゲームの言葉）、列、決まった欄、所属、承諾待ちの招待（ワークスペースごとに1件。社内ツールの分は e2e の取り消しが消し、デザイン相談室の分は招待だけが届いた人（ヒナタ）宛てで、e2e の承諾が使う）、区分とリポジトリ（受託開発チームに2つずつ、社内ツールに1つずつ。エピック、親のないタスク、ストーリーの下のタスクに少し振る）、エピック（受託開発チームに1件。その下に、配下のタスクがすべて完了したストーリー1件。討伐隊は3人で、うち1人（ユイ）は所属が無いので、エピックの画面で「（離脱済み）」と出る）、親のないストーリー、タスク（親のないタスクと、ストーリーの下の未完了のものと完了したもの。期日が過ぎたものと今週のものを含む）、先のスプリント（受託開発チームに2つ。名前のないものと名前のあるもの。それぞれにストーリーの下の未完了のタスクを1件ずつ入れ、入った行（`sprint_entries`）を置く。社内ツールとデザイン相談室には置かない）、変更の履歴（組織の作成と最初の管理者の指名、受託開発チームの作成と所属、あおば開発の一時的な停止と再開）、経験値の明細（あおば開発のミナトに完了したタスクの起票と完了の2行。ひばり工房のミナトに、自分の設定の画面の「続きを読む」を確かめる、完了と打ち消しをくり返した52行）。日時は 2026-10-20 前後に固定。末尾に、e2e の組織の言葉づかいと既定のテーマ（`e2e/organization-look.test.ts`）だけが使う3つ目の組織（くもラボ。その e2e が組織の値を書き換えるので、ほかのファイルが確かめる組織と分けた）と、その中の3人（管理者、テーマを選んでいない一般、テーマを選んだ一般。どれもほかの組織に入らない専用のアカウント）、一般の2人が入るためのワークスペース1つ |
| `sessions.ts` | ログインに使うセッションのトークン10個と、運用者のログインの ID |

## セッション

トークンの値の置き場所は `sessions.ts` だけ。`sessions.token_hash` にはその SHA-256 の16進を、`last_used_at` には流した時刻を、`expires_at` にはその30日後を入れ、切れたら流し直す。人が画面を開くときは `pnpm dev:open [--preview] [who] [path]` が、このトークンの Cookie を置いたブラウザで開く（`docs/development.md` の「開発とテストでのログイン」）。手で Cookie を置くときの名前は、画面を開く URL が http の localhost（`pnpm dev`、`pnpm preview`）なら `sg_session`、https なら `__Host-sg_session`（`src/shared/session-cookie.ts` の `sessionCookieName()`）。e2e も同じ関数で名前を決める。

| キー | 人 |
| --- | --- |
| `admin` | あおば開発の管理者（ミナト）。ひばり工房では一般のユーザー |
| `member` | あおば開発の一般のユーザー（ハルカ） |
| `otherOrg` | ひばり工房だけに入れる管理者（リン） |
| `invitee` | どの組織にも `users` の行を持たず、ひばり工房のデザイン相談室への承諾待ちの招待だけが届いた人（ヒナタ）。e2e が承諾すると、デザイン相談室の一般のメンバーになる（`pnpm db:seed` で戻る） |
| `operator` | どの組織にも属さない運用者。ログインの ID は `.dev.vars.example` の `OPERATOR_LOGIN_IDS` と同じ `github:9000000000000001`（実在の人に当たらないよう、GitHub がまだ振っていない桁にした） |
| `adminLogout` | `admin` と同じアカウント（ミナト）の2本目。e2e のログアウトが消す行 |
| `operatorLogout` | `operator` と同じアカウントの2本目。e2e のログアウトが消す行 |
| `lookAdmin` | くもラボの管理者（カイ）。e2e の組織の言葉づかいと既定のテーマ（`e2e/organization-look.test.ts`）が使う |
| `lookMember` | くもラボの一般のユーザーで、テーマを選んでいない（ソウタ） |
| `lookThemed` | くもラボの一般のユーザーで、自分のテーマ（シンプル（ダーク））を選んでいる（コハル） |

e2e は seed のセッションを全ファイルで共有し、ファイルを並列に走らせる。共有の `admin` や `operator` をログアウトすると、ほかのテストが 401 で落ちるので、ログアウトの e2e（`e2e/logout.test.ts`）は専用の2本だけを消す。ログアウトは今のセッションだけを消すので、同じアカウントの `admin` と `operator` は残る。消えた行は `pnpm db:seed` で戻る（`pnpm e2e` は毎回流し直す）。

## 本番に入れない

トークンは、リポジトリを読める人なら誰でも知っている値。本番の D1 に入れば、その人たちが管理者や運用者としてログインできてしまう。

- `scripts/db-seed.ts` が付けるのは `--local` だけで、`--remote` はフックの `guard-bash.mjs` も止める
- `seed/` の SQL は `wrangler d1 execute --remote` に渡さない
