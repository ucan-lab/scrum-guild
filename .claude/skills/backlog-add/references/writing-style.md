# 書き手の癖（投稿コメントの文体）

Phase 2 で投稿コメントを生成する際、ここに蓄積された癖に合わせる。
Phase 3 で「Phase 2 ドラフト」と「実際に投稿されたコメント」を差分比較し、判明した癖をここに追記していく。
初回は空でよい。セッションごとに学習して育てる。

## 記録フォーマット

各癖を1項目として、根拠（どのセッションのどの差分から学んだか）を添える。

```
- <癖の内容（する / しない）>
  - 例: ドラフト「〜してください。」→ 投稿「〜をお願いします。」（#1120 A-1）
```

## 学習済みの癖

- 冒頭にプロセスのメタ注記を入れない。「〜を踏まえて更新しました」等の経緯説明を削り、本題（レビュー報告＋A/B の依頼）だけで始める。
  - 例: ドラフト「実装計画をレビューしました。（Backlog … を踏まえて更新しました）」→ 投稿「実装計画をレビューしました。」（#1120 冒頭）
- 1文＝1行で改行する。複数の文を1行に流さず、句点ごとに改行する。各項目内では、説明文と締めの依頼文（「〜してください」）の間に空行を1つ入れる。
  - 例: ドラフト「調査ありがとうございます。B の結果と A の反映を確認しました。着手前に…お願いします。」（1行）→ 投稿は3行に分割（#1120 冒頭・A-1）

## カテゴリの目安

- **語調・敬体** — 依頼表現、断定/やわらげ、絵文字/記号の有無。
- **粒度** — 箇条書きの細かさ、根拠リンクの付け方、引用の要否。
- **構成** — 見出しの付け方、A/B の順序、冒頭文の有無。
- **固有表現** — 用語の言い換え（社内用語・API 名の表記ゆれ）。※ 特定プロジェクト固有の用語対応はここではなくメモリ（reference）に寄せる。
