# 名前の決定の記録

状態: 確定（2026-10-24）。表記の決まりは `requirements.md` の「名前」

## 決めたこと

名前は Scrum Guild（スクラムギルド）にする。リポジトリ、パッケージ、ドメインは `scrum-guild`。

## 経緯

| 時期 | 名前 | 改めた理由 |
| --- | --- | --- |
| 〜2026-10-20 | scrum-quest | 2026-10-16 に、アジャイル ビジネス インスティテュート株式会社（ABI）が、遊びながらスクラムの基本を学べる無料の Web コンテンツ「SCRUM QUEST」を PR TIMES で公開した。どちらも「スクラム × ゲーム」で検索したときにまぎれるため、「Scrum」と「Quest」の両方を外した |
| 2026-10-20〜2026-10-24 | Team Leveling | 名前にスクラムが入っておらず、何の道具かが名前から伝わりにくかった |

## Scrum Guild にした理由

- 「Scrum」が入っていて、スクラムでチームのタスクを回す道具だと名前で伝わる。
- 「Guild」は、デザインの土台にした「ギルドの帳簿」の世界観と、ゲームの言葉の側に合う。スクラムの言葉とゲームの言葉の両方を持つこの道具の性格を、名前の前後で表す。
- 「Quest」を使わず、ABI の「SCRUM QUEST」とは後ろの語で見分けられる。「Scrum」が重なるので、検索で並ぶことは受け入れる。

名前からは記録（完了の記録、請求の根拠）の役目が読み取れない。README の一行目で補う。
