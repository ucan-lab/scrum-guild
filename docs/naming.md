# 名前の決定の記録

状態: 確定（2026-10-20）。表記の決まりは `requirements.md` の「名前」

## 決めたこと

名前は Team Leveling（チームレベリング）にする。リポジトリ、パッケージ、ドメインは `team-leveling`。

## 改めた理由

はじめは scrum-quest と呼んでいた。2026-10-16 に、アジャイル ビジネス インスティテュート株式会社（ABI）が、遊びながらスクラムの基本を学べる無料の Web コンテンツ「SCRUM QUEST」を PR TIMES で公開した。

中身は違うが、どちらも「スクラム × ゲーム」で、検索したときにまぎれる。そのため「Scrum」と「Quest」の両方を名前から外すことにした。

## 比べた候補

デザインの土台にした「ギルドの帳簿」の世界観に寄せて、次の候補を挙げた。

| 名前 | 見送った理由 |
| --- | --- |
| Guild Ledger | 少し長い |
| Guildbook | 「〜book」で終わる名前が多い |
| Taskguild | 響きが平凡。似た名前の TaskGuru がある |
| Bounty Board | 「Bounty」はバグの懸賞金の意味でも使われる |
| Adventurer's Log | 長く、アポストロフィがリポジトリ名に入れにくい |

## Team Leveling にした理由

- 持ち主が好きな『俺だけレベルアップな件（Solo Leveling）』から思いついた。Solo を Team に替えたことが、この道具の狙いの説明になる。リーダーが一人で詳細を書き、聞き取って抱え込むのではなく、メンバーが自分から起票して、チーム全体でレベルを上げる。
- 「leveling」に意味が2つある。ゲームの「レベル上げ」は経験値とレベルの仕組みに、仕事の「負荷の平準化」は積載量に、それぞれ当たる。
- 「チーム」が入っていて、初版からチームで使う道具だと分かる。

名前からは記録（完了の記録、請求の根拠）の役目が読み取れない。README の一行目で補う。
