# 競合サービスの調査

状態: 調査。2026-10-28 に各社の公式の料金ページとヘルプで確かめた。価格は改定が多いので、値付けを決める前に出典で確かめ直す。

1つのサービスのことは「サービスごとの節」の節を読めばひと通り分かる。サービスをまたいで比べるときは「横断の表」を使う。横断の表の数字は、サービスごとの節から取っている。

- 1人あたりの単価から人数分を出した額は「計算」と書く。
- 公式で確かめられなかった値は「確認できなかった」と書き、推測では埋めない。
- 「ゲームの仕組みが無い」は、公式の料金ページと機能の案内に書かれていないという意味で、製品の中までは確かめていない。

## 要点

- ゲームの仕組み（経験値、レベル、報酬）と、Backlog と GitHub の取り込みを両方持つサービスは見つからなかった。タスク管理の道具はどれもゲームの仕組みを持たず、ゲーム化の道具はどれも Backlog とつながらない。
- 組織ごとの定額で円建てなのは、Backlog と My Redmine だけ。Planio も組織ごとの定額だが、請求はユーロ建て。RedmineUP Cloud は組織ごとの定額のドル建て。ほかはユーザー単位で、多くはドル建て。
- 値付けに効く変化は次の2つ。
  - Backlog の 2027-01-01 のプラン改定。
    - 最安の有料プランが月 ¥21,000（15人）に上がり、フリーの上限は10人から5人に下がる。
    - 現行プランの新規の受付は 2026-12-31 で終わり、スターター（月 ¥2,700）は新しいプランの一覧に無い。
    - 既存の契約は、2027-01-01 以降の最初の更新日から新しいプランに移る。
  - Jooto の一般提供の終了（2027-07-31）。
    - Jooto の移行の案内ページは、Backlog、Asana、CrewWorks、スーツアップ、Lychee Redmine、Flagxs を「移行支援あり」として載せる。
    - Backlog は、2026-12-31 までに始めれば 2027-03-31 まで無料のキャンペーンを出している。
- 〜50人の月 ¥10,000 は、My Redmine のスタンダード（1,000人まで、前払いで月 ¥10,000）と同じ額。〜15人の月 ¥3,000 は、Jira Free と GitHub Free（どちらも無料）と並べられる。
- 工数の管理まで入れると、Redmine 系も安くない。Lychee Redmine のプレミアムは10人で月 ¥39,000（計算）。
- 経験値を「人の評価に使わない」とうたう製品は、早期アクセス中の Questline だけ。Questline は、ゲームのデータを人事のシステムから切り離すことと、管理者が評価のために書き出せないことを明言する。逆に、devActivity は人事評価の材料を売りにし、Unipos は FAQ で「バリューを体現する従業員を評価」できると答える。

## サービスごとの節

タスク管理の道具は、概要、プラン、無料の範囲とお試し、機能、支払いの形、確信度の低い点、出典の並びで書く。ゲーム化の道具は、概要、プラン、ゲームの仕組みとランキング、確信度の低い点、出典の並びで書く。出典の確認日は、書いていないものはすべて 2026-10-28。

### Jira

#### 概要

- ソフトウェア開発のチーム向け。課金はユーザー単位。日本の顧客には円の価格表がある。税込か税抜かは確認できなかった。日本語の画面がある。
- 2026-10-13（太平洋時間）に Cloud の価格を上げた。
  - Standard と Premium は約7〜10%（5,000席未満は約7%）、Enterprise は約8%。
  - 新規の購入、更新、上位プランへの変更から効く。

#### プラン

| プラン | 月払い | 年払い（月あたり） | 上限 |

- 値上げの率の出典は、販売パートナー（Adaptavist）の記事と価格の追跡サイトだけ。

### Linear

#### 概要

- ソフトウェア開発のチーム向け。課金はユーザー単位（停止していないユーザーの数）。ドル建て。税は請求先の住所で決まる。
- 日本語の画面は無いと見られる。表示の言語の設定がヘルプに無く、紹介のサイトも英語だけ。

#### プラン

| プラン | 月払い | 年払い（月あたり） | 上限 |
| --- | --- | --- | --- |
| Free | $0 | $0 | 人数無制限、チーム2つ、課題250件、ファイル 10MB |
| Basic | 1人 $12 | 1人 $10 | チーム5つ、課題とファイルは無制限 |
| Business | 1人 $18 | 1人 $16 | チームと課題は無制限 |
| Enterprise | 年払いだけ | 見積もり | 無制限 |

- 10人: Basic。月払い $120、年払いは月あたり $100（どちらも計算）。
- 50人: チームが5つまでなら Basic で月払い $600、年払い $500。非公開のチーム、ゲスト、Insights が要るなら Business で月払い $900、年払い $800（どれも計算）。

#### 無料の範囲とお試し

- Free は人数無制限で、課題250件とチーム2つまで。全員が管理者になる。
- お試しは料金ページにもヘルプにも記載が無い。

#### 機能

| 機能 | 使えるプラン |
| --- | --- |
| スプリントとポイント | 全プラン（サイクルと見積もり。ベロシティと、直近3サイクルからのキャパシティを出す） |
| エピックと親子 | 全プラン（サブ課題、プロジェクト、イニシアチブ）。サブチームは Business から |
| ガント | 無い（プロジェクトのタイムラインの表示はある） |
| 時間の記録 | 無い（Everhour などの連携で足す） |
| 書き出し（CSV など） | 全プラン。データウェアハウスへの同期は Enterprise |
| 権限と監査ログ | 非公開のチームとゲストは Business から、監査ログは Enterprise |
| SSO（SAML）と SCIM | Enterprise |

| API | 全プラン（GraphQL と Webhook） |
| Backlog との連携 | 無い |
| GitHub との連携 | 全プラン（課題の双方向の同期も全プラン） |
| AI | Linear Agent は全プラン。Triage Intelligence と Code Intelligence は Business から |
| ゲームの仕組み | 無い |

分析は、Insights が Business から、Dashboards が Enterprise から。

#### 支払いの形

- 年払いの割引は Basic 約17%、Business 約11%（計算）。Enterprise は年払いだけ。
- 月払いは、月の途中で足した人を翌月から請求し、外した人の残りの日数は返さない。年払いは、足した人を日割りで請求し、停止した人を日割りでクレジットにする。
- 途中で解約しても返金しない。

#### 確信度の低い点

- 料金ページの本文に見えるのは年払いの額（$10、$16）だけ。月払いの $12 と $18 は、ページのプログラムの中の値（`basic_monthly_12`、`business_monthly_18`）による。
- 監査ログ、SAML、SCIM を Enterprise からとしたのは、料金ページの Enterprise の説明に従ったため。ページのプログラムでは、旧プランの一部でも使える扱いだった。
- 日本語の画面が無いことを公式に書いた文書は見つからなかった。

## Scrum Guild にとっての示唆

### 欠けている機能の候補

`ideas.md` の「必須と言える機能が欠けていれば取り入れる」の材料。

- 時間の記録: 受託と SES の請求の根拠では、Redmine 系と Jira が工数を記録して作業の分類ごとに CSV で出すのが定番になっている。Scrum Guild の「記録」は何をいつ終えたかを残し、時間を持たない。想定顧客の請求が成果物の単位か工数の単位かで、必須かどうかが分かれる。Lychee Redmine は工数の管理を上のプラン（プレミアム）に置き、10人で月 ¥39,000 になる。
- ガント: Backlog（エコノミーから）、Jira、Redmine 系が持つ。受託の顧客へ見せる計画の資料として求められる可能性がある。
- 権限と監査ログ、IP 制限: どの競合も上のプランの売りにしている。セキュリティチェックシートで問われる項目と重なる（`business.md` の「事業にするときに要るもの」）。Backlog は 2027 から IP 制限を全有料プランに広げる。

### 値付け

- 〜15人の月 ¥3,000 は、Jira Free と GitHub Free の無料、Backlog の現行スターターの月 ¥2,700 と比べられる。Backlog の新プランが始まると、15人以下で Backlog を使い続けるには月 ¥21,000 かかる。Backlog から乗り換えるチームには、移行の手間を払っても安い。
- 〜50人の月 ¥10,000 は My Redmine の前払いと同じ額で、My Redmine は1,000人まで使える。人数の段階で価値を説明しにくい。RedmineUP Cloud の Medium（50人、月 $203）よりは安い。
- 取り込み元の Backlog を使い続けるチームには、Backlog の料金に上乗せになる。Backlog から乗り換える先として売るのか、Backlog と GitHub の上に重ねる道具として売るのかで、比べられる相手が変わる。
- 年払いの割引は、多くが約17%（12か月分を10か月分の値段にする形）で、Scrum Guild の年払い（2か月分無料）も同じ。Backlog は5%と小さく、Redmine 系の国産（My Redmine、Lychee Redmine）は割引を置かない。
- Jooto の終了で移る先を探すチームがいる。Backlog、Asana、Lychee Redmine などが移行の支援を出している。
